## Featured Projects 📖

### ⚡ [AI.ciOne](https://github.com/aicione/aicione) & [CEML](https://github.com/aicione/ceml-lang)
An automated electronic circuit solver pipeline. Features CEML, a domain-specific language for analytical circuit representation, coupled with a mathematical solver utilizing SymPy.
**Technologies:** Python • SymPy • Domain-Specific Language (DSL)

### 🔎 [Ground Source Engine](https://github.com/MkDev21IA/ground-search-engine)
Open-source search and factual synthesis engine (LLM) focused on rigorously grounded knowledge. Virtually every substantive claim generated by the model is accompanied by a verifiable primary or secondary source, cited inline in markdown format.
**Technologies:** Python • LLMs • RAG • Markdown

### 👔 [CTAIO Readiness Matrix](https://github.com/MkDev21IA/ctaio-readiness-matrix)
An AI-powered executive career matching and competency gap remediation platform designed for ctaio.dev — the premier intelligence publication for CTO, CIO, CAIO, and CDAO convergence.
**Technologies:** Python • LLMs • Web Framework

### 📊 [Financial Data ETL Pipeline](https://github.com/MkDev21IA/extrator-financas-inter)
An end-to-end automated ETL solution to extract and process financial data. The application is containerized to ensure consistent deployment and isolated execution.
**Technologies:** Python • Docker • Data Engineering

### 🚁 Drone Autonomous System
Development of autonomous drone systems involving computer vision, embedded systems and software integration.
**Technologies:** Python • OpenCV • Pixhawk • PyMAVLink
